# IPR GAMER BINGO v4.0 — Base oficial

Esta es la única carpeta oficial del proyecto. No la coloque dentro de otra versión y no copie carpetas `.git` antiguas.

## Inicio local

Windows: ejecute `INICIAR_IPR_GAMER.bat`.

Manual:

```bash
npm start
```

Abra `http://localhost:3000`.

## Publicación

- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/health`

## Flujo de trabajo

1. Reemplazar únicamente los archivos modificados dentro de esta carpeta.
2. Probar localmente.
3. GitHub Desktop: Commit to main.
4. Push origin.
5. Render despliega automáticamente.

## Funciones incluidas

- Crear y unirse a salas.
- Invitación por enlace y WhatsApp.
- Mínimo 2 cartillas por jugador.
- Sala de espera y anfitrión.
- Cuenta regresiva sincronizada.
- Sorteo y marcado automáticos.
- Cantos tradicionales.
- Premio, saldo e historial.
- Retorno al lobby de la sala sin perder la sesión.
- Salida completa separada.
- Reconexión por sesión.
- Ciclo de 10 juegos y APAGÓN.
